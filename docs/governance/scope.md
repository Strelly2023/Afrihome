## Governance Scope

Only the following paths are governed:

- afritech/
- config/
- tests/
- adr/

Everything else is **out of scope by definition**.

This is architectural law, not convenience.

by governance guards unless explicitly requested:

- _quarantine/

- tools/ (legacy tools)
- docs/
- all *.txt snapshot files
